# How It Works 0.1.0

Turn the current repository into one visual product explanation for a non-technical product owner.
Explain what works, what the evidence proves, and where to investigate a symptom.

Status: local release candidate. Public release, tag `v0.1.0`, and directory distribution are `planned`.
The release archive and its SHA-256 checksum remain `pending`.
This document is release content for preparation, not a publication record.

## Package

- One shared workflow to create or refresh project-root `HOW_IT_WORKS.md` in the user's language.
- Two to four useful Mermaid diagrams and plain-language concept explanations.
- Four evidence levels: code, local tests, real runtime, and user acceptance.
- A repeatable project instruction updater with English and Chinese blocks.
- Portable plugin metadata, a Codex overlay, and a Claude repository marketplace.
- A synthetic demo and local checks for instructions, package structure, links, and known privacy risks.

See the [English README](../../README.md) or [中文说明](../../README.zh-CN.md) for install commands and the first-use prompt.
Use the [synthetic example](../../demo/expected/HOW_IT_WORKS.md) to inspect the intended output.

## Evidence and limits

Local tests and manifest validation cover package behavior in synthetic scenarios.
The [recorded skill-enabled agent run](../../evals/README.md) met 6 of 7 rubric checks.
It used two diagrams, while that case requires three.
The skill permits two to four diagrams. This score remains a failed case result.

Public Codex, Claude Code, and generic-client installation still need end-to-end verification.
Official directory acceptance and product-owner acceptance remain unverified.
The skill adds no telemetry or upload service. Clients and installers retain their own data policies.
Read the [distribution register](../distribution.md) before you use a public channel.

## Requirements

Use an Agent Skills client with repository access, local file tools, and Python 3.9 or later.
Keep the complete skill directory for a manual install.
The updater changes project instructions. Review its report and the generated document before acceptance.
See [security](../../SECURITY.md) and [contribution guidance](../../CONTRIBUTING.md) for safe reports.
