## Package

The skills invoke a bundled Python updater that changes project-local instruction files.
The [OpenAI desktop-only guide](https://developers.openai.com/plugins/deploy/desktop-only) requires a local execution declaration for this package.
Root `plugin.json` declares `requires_local_executor: true` under `extensions.com.openai`.
The legacy `.codex-plugin/plugin.json` declares the same field at its top level.
No MCP server or new permissions exist in this patch.

`VERSION`, all plugin manifests, the Claude marketplace, and both skill metadata blocks use version `0.1.1`.
The package checker rejects absent, false, or non-boolean local execution declarations.
The updater and document workflow retain their current behavior.

## Evidence and limits

Local package tests cover both field locations and version parity.
The repository checker, both Agent Skills validators, Claude strict validation, nine synthetic demo tests, and privacy history checks passed locally.
These checks establish local package consistency. They do not prove a clean OpenAI desktop installation or portal acceptance.
No clean v0.1.1 desktop install, model run, or portal acceptance existed at snapshot verification time.
Directory acceptance and product-owner acceptance also lacked evidence at that time.

Use Python 3.9 or later and a client with authorized local execution.
Read the [distribution register](../distribution.md) for evidence scope and the preserved v0.1.0 release identity.
For public channel evidence after external actions, use that register on `main`.
